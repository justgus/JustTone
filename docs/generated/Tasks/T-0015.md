**Rationale:**
Build generalized tuning on the core pitch engine and qualify their integrated domain behavior.

**Acceptance Criteria:**
1. Equal divisions, ratios, cents and explicit-frequency degree definitions resolve deterministically with the approved 4096-degree per-object bound.
2. Reference adjustment semantics for relative and explicit definitions are documented and tested; invalid ratios, non-finite values, overflow, invalid counts and out-of-range resolution are handled deterministically.
3. Contextual metadata and user-defined variants preserve specific system/tradition, region, instrument or musical context and supplied provenance without claiming a universal tuning.
4. Integrated named/direct pitch, tuning degrees and written/sounding values preserve precision and identity; calculated results satisfy ±0.1 cent.
5. Independent expected-value fixtures and T-0007 regressions pass through package, iPhone and Watch test hosts; core remains platform-neutral.

**Test Steps:**
- Test all four representations, equivalent ratio/cents values, reference changes, counts at and beyond 4096, invalid and non-finite inputs, overflow and supported-frequency boundaries.
- Test distinct contextual variants and repeated domain round trips; compare against independent expected-value fixtures.
- Run beta-toolchain package and iPhone/Watch host tests, including T-0007 regressions; record actual commands, destinations and residual cross-Epic acceptance work.
