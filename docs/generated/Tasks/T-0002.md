**Rationale:**
Accurate, safe, click-free tone generation is the core product capability.

**Acceptance Criteria:**
1. The engine accepts requested shared-domain frequencies and renders exactly one selected fundamental at a time without allocations, blocking, file I/O, or UI-state mutation in the render callback.
2. Start, stop, pitch, and level changes use finite ramps or crossfades that prevent discontinuities; playback remains silent until explicit start.
3. Deterministic buffer tests qualify requested frequency, monophony, ramp continuity, amplitude bounds, clipping, and transition behavior.
