**Rationale:**
The primary interaction must be fast and readable while holding or playing an instrument.

**Acceptance Criteria:**
1. A musician can choose a profile and note and deliberately start or stop its tone with few taps.
2. The UI displays note name, octave, and frequency clearly.
3. Controls support Dynamic Type, VoiceOver, sufficient contrast, and non-color state cues.
4. The visual identity resembles the JustTune product family without confusing either app.

**Test Steps:**
- Exercise primary flows on representative iPhone sizes.
- Run accessibility inspection and VoiceOver checks.
