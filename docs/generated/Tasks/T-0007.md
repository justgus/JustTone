**Rationale:**
Establish the tested pitch semantics on which generalized tuning depends.

**Acceptance Criteria:**
1. Named pitches retain note, accidental, octave and preferred spelling; default twelve-tone equal temperament uses A4 = 440.0 Hz.
2. A4 accepts 350.0 through 500.0 Hz in 0.1 Hz increments; recalculation preserves identity. Direct frequencies accept 16.0 through 12000.0 Hz in 0.1 Hz increments without a note name.
3. Written/sounding pitch and reversible transposition preserve identity and spelling; internal numeric values remain locale-independent.
4. Calculated frequencies retain internal precision and satisfy ±0.1-cent accuracy with deterministic invalid-input handling and boundary tests.
5. The same domain fixtures pass in package, iPhone and Watch test hosts.

**Test Steps:**
- Test default pitch, enharmonic pairs, octave crossings, all supported A4 reference increments and direct-frequency endpoints; reject or explicitly document normalization of invalid inputs.
- Compare independently derived frequency fixtures; test reversible transposition, spelling preservation, non-finite inputs and out-of-range results.
- Run beta-toolchain package tests; inspect schemes/destinations and run shared fixtures through iPhone and Watch test hosts, recording actual commands and results.
