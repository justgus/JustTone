# EP-001: Project Foundation and Platform Architecture

**Status:** Closed
**Owner:** 
**Start Date:** TBD
**Target Close Date:** TBD
**Close Date:** 2026-09-06

**Goal:**
Establish the correctly named Swift 6 iPhone, Watch, shared-domain, and test architecture.

**Rationale:**
Musicians need a fast reference pitch and reusable tunings without the complexity of a microphone tuner.

**Scope:**
- Git and GitHub repository foundation
- Swift 6 iPhone and Watch project, shared-domain module, and test targets
- Distinct identities, build configurations, localization and privacy foundations
- Architecture boundaries and beta-Xcode build/launch evidence

**Out of Scope:**
- Microphone pitch detection
- Accounts and cloud services
- Advertising and analytics
- Non-iPhone iOS-family app experiences

**Acceptance Criteria:**
- JT-AC-001: The repository builds correctly named iPhone, Watch, shared-domain, and test targets with Swift 6 and the approved deployment targets.
- JT-AC-002: Build settings, bundle identities, entitlements, background modes, document types, and App Groups are distinct from JustTune and trace to requirements.
- JT-AC-003: The shared architecture isolates deterministic domain logic, persistence, synchronization, UI state, and real-time audio responsibilities.
- JT-AC-004: The project uses only approved Apple frameworks and project-owned runtime code, with localization and privacy-manifest foundations present.
- JT-AC-005: All schemes build and launch with Xcode-beta and retain an explicit final-Xcode requalification gate.
